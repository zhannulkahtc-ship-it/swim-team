# Селяевы Swim Team — premium edition

## Запуск
Распакуйте ZIP и откройте `index.html` в браузере. Сайт работает без установки, домена и регистрации.

## Возможности
- Три профиля: Всеволод, Давид и Мирон.
- Добавление результатов, статусы PB / DSQ / DNS / EXH.
- История с фильтрами, лучшие времена по дистанции/стилю/длине бассейна.
- График прогресса, экспорт и импорт JSON.
- Адаптивный тёмный премиальный интерфейс.

## Важное о данных
В начальный архив включены шесть результатов Всеволода и Давида, доступных из последнего обсуждения. Это не полная история всех заплывов. Результаты Мирона и более ранние старты нужно импортировать/добавить. Данные хранятся локально в браузере; резервные копии можно скачать кнопкой «Экспорт архива».

## Бесплатная публикация
1. Создайте публичный репозиторий на GitHub, например `swim-team`.
2. Загрузите `index.html` в корень репозитория.
3. Перейдите в Settings → Pages.
4. Выберите Deploy from a branch, ветку `main`, папку `/ (root)`, нажмите Save.
5. Сайт будет опубликован по адресу вида `https://ВАШ-ЛОГИН.github.io/swim-team/`.

GitHub Pages публикует сам сайт, но данные `localStorage` не синхронизируются между устройствами. Для общей базы понадобится отдельный backend.
